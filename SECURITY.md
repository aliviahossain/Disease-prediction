# Security Policy

## Supported Versions


We take security seriously in the Disease Prediction project. The following table outlines which versions are currently supported with security updates and patches:

| Version | Supported |
| ------- | --------- |
| 5.1.x   | ✅ Yes    |
| 5.0.x   | ❌ No     |
| 4.0.x   | ✅ Yes    |
| < 4.0   | ❌ No     |

---

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it responsibly. **Do not disclose security vulnerabilities publicly** in public issues or pull requests until they have been addressed and a patch has been released.

### How to Report:
* **Private Disclosure:** Please report security issues by opening a private security advisory or contacting the maintainers directly via GitHub profile communication.
* **Information to Include:** 
  * A description of the vulnerability and its potential impact.
  * Steps, code snippets, or a proof-of-concept to reproduce the issue.
  * Any recommended fixes or mitigation steps if available.

### What to Expect:
* **Acknowledgment:** You will receive an initial response acknowledging receipt of your vulnerability report within **48 hours**.
* **Updates:** We will provide regular updates on our progress regarding verification, patch development, and deployment.
* **Resolution:** Once verified, a patch will be prepared and released in the next patch or minor version update, accompanied by a public advisory crediting the reporter (unless requested otherwise).
